# Real Kuro Siwo Model Runs & Error Analysis Gallery

This directory contains real sample inferences generated by [`scripts/visualize_real_runs.py`](file:///home/adi/projects/dhara/scripts/visualize_real_runs.py) using the trained ONNX segmentation model evaluated on real Sentinel-1 SAR triplets from Kuro Siwo disaster events.

---

## 1. Quick View
Open [`reports/real_runs/index.html`](file:///home/adi/projects/dhara/reports/real_runs/index.html) in your web browser, or view individual high-resolution panels below.

Each multi-panel figure displays:
1. **Post-event VV Backscatter (dB):** Radar intensity during the disaster.
2. **Pre-event VV Backscatter (dB):** Normal dry-state radar baseline.
3. **Temporal Difference $\Delta \sigma^0$ (dB):** Post minus Pre backscatter drop.
4. **Ground Truth Mask:** Official disaster annotation (cyan = flood, dark blue = permanent water, beige = dry land).
5. **Model Predicted Probability $P(\text{flood})$:** Softmax calibrated flood probability.
6. **Error / Confusion Diagnostic Map:**
   - **🟩 Green (TP):** True Positive — Correctly detected inundated pixels.
   - **🟥 Red (FP):** False Positive — Spurious over-prediction.
   - **🟦 Blue (FN):** False Negative — Missed flood pixels.
   - **⬜ Light Gray (TN):** True Negative — Correctly identified dry land.
